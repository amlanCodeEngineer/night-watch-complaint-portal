# Night Watch Complaint Portal

A themed frontend project built while revising core JavaScript concepts such as **form validation, regex, DOM manipulation, and event handling**.

This project simulates a secure complaint system with a cinematic night-watch (Batman-inspired) UI.

---

## 🔧 Tech Stack
- HTML5
- CSS3
- JavaScript

---

## ✨ Features
- Client-side form validation (Name, Email, Password, Message)
- Regex-based input checks
- Password visibility toggle
- Clear & reset functionality
- Success screen with animated transition
- Responsive, dark-themed UI
- Deployed using GitHub Pages
